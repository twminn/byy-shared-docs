# Legacy Team

This directory is for files shared with the **Legacy Team**, responsible for maintaining and operating the Best Year Yet PRO application — the original ColdFusion-based platform.

## About

The Legacy Team manages the BYY PRO application, which provides the core Best Year Yet planning experience for existing subscribers. The application is built on Adobe ColdFusion with a Microsoft SQL Server backend, hosted on AWS.

## Repository

- **Application repo**: [byy_pro](https://github.com/twminn/byy_pro.git)

## How to Use This Folder

Other teams should place files for the Legacy Team in this directory:

- Task requests and feature specifications
- Integration documentation
- Migration plans and coordination notes
- Data or API handoff documents
