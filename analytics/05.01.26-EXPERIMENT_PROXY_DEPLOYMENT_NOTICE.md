# Deployment Notice: Experiment Proxy Live for Landing Pages

**Date:** May 1, 2026
**Priority:** High — Read before making CloudFront or DNS changes
**Owner:** Analytics Team (Marigold ONE11)
**Audience:** Frontend Team, DevOps, anyone managing bestyearyet.com infrastructure

---

## What Happened

On May 1, 2026, the pricing experiment proxy was deployed for `new.bestyearyet.com` and `gift.bestyearyet.com`. This inserts a CloudFront + Lambda@Edge layer between visitors and the existing static sites.

**The proxy is currently in passthrough mode** — no experiments are active yet, so all visitors see the default (control) pricing. When the first experiment is activated, visitors will begin receiving variant assignments.

---

## What Changed

### CloudFront Distributions

| Domain | Before | After |
|--------|--------|-------|
| `new.bestyearyet.com` | Served by `E3V0XMOV33VVAD` directly | Served by new proxy `ELBY7IAJQ7USO` → forwards to `E3V0XMOV33VVAD` |
| `gift.bestyearyet.com` | Served by `E3C9LYKEHPGWAR` directly | Served by new proxy `E20V8MRUX3O15O` → forwards to `E3C9LYKEHPGWAR` |

The original distributions (`E3V0XMOV33VVAD`, `E3C9LYKEHPGWAR`) still exist and still serve content from S3. They just no longer have public aliases — traffic reaches them through the proxy.

### DNS (Route 53)

| Record | Before | After |
|--------|--------|-------|
| `new.bestyearyet.com` | CNAME → `d152y14hy94k1u.cloudfront.net` | A (alias) → `d20798atdjrwpj.cloudfront.net` |
| `gift.bestyearyet.com` | CNAME → `d3qf7jdc5zlfye.cloudfront.net` | A (alias) → `d2lsj59hdfwtyv.cloudfront.net` |

DNS records for these domains are now managed by Terraform in `byy-marketing-analytics`.

### What Did NOT Change

- S3 buckets (`byy-landing-876524020257`, `byy-gift-landing-876524020257`) — untouched
- S3 deploy workflows (`deploy-new.yml`, `deploy-gift.yml`) — still work as before
- Site content, functionality, and performance — unchanged (proxy adds <5ms latency)
- `bestyearyet.io` (Rails app) — no changes, proxy not active for .io

---

## What Would Break Things

| Action | Risk |
|--------|------|
| Re-adding `new.bestyearyet.com` or `gift.bestyearyet.com` as aliases on distributions `E3V0XMOV33VVAD` / `E3C9LYKEHPGWAR` | **Will fail** — CloudFront enforces unique aliases |
| Manually editing Route53 A records for `new.bestyearyet.com` or `gift.bestyearyet.com` | **Terraform drift** — will be overwritten on next apply |
| Running CloudFormation stacks that reference these aliases (e.g., `cloudformation-gift.yaml`) | **Conflict** — may attempt to reclaim aliases |
| Deleting or disabling distributions `E3V0XMOV33VVAD` / `E3C9LYKEHPGWAR` | **Breaks proxy** — these are the origin for the experiment layer |

## Rollback Plan

If the proxy causes any issues:

1. **Immediate (< 5 min):** Analytics team disables Lambda@Edge associations on the proxy distributions → traffic passes through unmodified
2. **Full rollback (< 15 min):** Remove aliases from proxy distributions, re-add to original distributions, update Route53 back to CNAME records
