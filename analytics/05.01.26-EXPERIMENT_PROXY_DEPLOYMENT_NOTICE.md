## What Happened

On May 1, 2026, the pricing experiment proxy was deployed for **all BYY web properties**:

- `bestyearyet.com` (main site)
- `www.bestyearyet.com`
- `new.bestyearyet.com` (landing page)
- `gift.bestyearyet.com` (landing page)
- `bestyearyet.io` (Rails app)

This inserts a CloudFront + Lambda@Edge layer between visitors and the existing origins (S3 for static sites, ELB for Rails).

**The proxy is currently in passthrough mode** — the experiment is in DRAFT state, so all visitors see the default (high/control) pricing. When the experiment is activated, visitors will begin receiving variant assignments.

## What Would Break Things

| Action | Risk |
|--------|------|
| Re-adding aliases to old distributions (`E2AJ6RQ8SE9VAY`, `E3V0XMOV33VVAD`, `E3C9LYKEHPGWAR`) | **Will fail** — CloudFront enforces unique aliases |
| Manually editing Route53 records for any covered domain | **Terraform drift** — will be overwritten on next apply |
| Running CloudFormation stacks that reference these aliases (e.g., `cloudformation-gift.yaml`) | **Conflict** — may attempt to reclaim aliases |
| Deleting or disabling origin distributions (`E2AJ6RQ8SE9VAY`, `E3V0XMOV33VVAD`, `E3C9LYKEHPGWAR`) | **Breaks proxy** — these are the origins for the experiment layer |
| Changing the ELB DNS name for the Rails app without coordination | **Breaks `.io` proxy** — origin will not resolve |

## Architecture Diagram

```
STATIC SITES (bestyearyet.com, new., gift., www.)

User → Route53 (A alias) → CF Proxy (Lambda@Edge) → CF Origin → S3
                                │
                                ├─ viewer-request: assign variant, set headers
                                └─ origin-response: set byy_exp_variant cookie

RAILS APP (bestyearyet.io)

User → Route53 (A alias) → CF Proxy (Lambda@Edge) → ELB → Rails
                                │
                                ├─ viewer-request: assign variant, set X-BYY-Variant header
                                └─ origin-response: set byy_exp_variant cookie
```

**For static sites:** The Lambda does NOT modify the HTML body. Content gating is handled client-side by reading the `byy_exp_variant` cookie. See [Landing Pages Integration](./05.01.26-PRICING_EXPERIMENT_LANDING_PAGES.md).

**For Rails:** The `X-BYY-Variant` header is available server-side. Rails renders only the assigned variant. See [Rails App Integration](./05.01.26-PRICING_EXPERIMENT_RAILS_APP.md).
