# Meta Pixel `fbq is not defined` Race Condition

**Date:** 2026-07-10  
**Priority:** Low (non-blocking, cosmetic console error) — **FIXED 2026-07-10**  
**Owner:** Analytics Team (GTM)  
**Fix:** GTM container version 14 — Meta Pixel Base now includes `fbevents.js` bootstrap; event tags guarded + sequenced. Script: `BYY-Marketing/scripts/fix_meta_pixel_fbq_race.py`  
**Environment:** Staging (`byy-staging.bestyearyet.io`) and likely Production  
**GTM Container:** `GTM-K9PVK9ZF`  
**Meta Pixel ID:** `1192403812300787`

---

## Issue

On initial page load, the browser console throws:

```
Uncaught ReferenceError: fbq is not defined
    at <anonymous>:1:423
    at gtm.js?id=GTM-K9PVK9ZF:725:429
```

This occurs because a GTM custom HTML tag calls `fbq(...)` before the Meta Pixel base code (`fbevents.js`) has finished loading. It is a timing/race condition within the GTM container configuration.

---

## Impact

- Console error on every page load (may confuse developers debugging other issues)
- The Meta Pixel event that triggers the error is **not delivered** on that page load
- Does not affect GA4 events, dataLayer, or any Rails-side functionality
- Does not affect the new tour funnel instrumentation (`tour_start`, `tour_step`, etc.)

---

## Root Cause

The GTM tag firing `fbq()` uses a trigger (likely "All Pages" or "DOM Ready") that executes **before** the Meta Pixel base code script has loaded and initialized the global `fbq` function.

The Meta Pixel base code loads asynchronously via GTM or a separate script tag, creating a race condition where the pixel function call can execute before the library is ready.

---

## Recommended Fix (in GTM web interface)

### Option A: Guard the fbq call (preferred, minimal risk)

In the GTM Custom HTML tag that calls `fbq()`, wrap it:

```html
<script>
  (function() {
    if (typeof fbq !== 'undefined') {
      fbq('track', 'PageView');
      // ... other fbq calls
    } else {
      // Retry once after pixel loads
      window.addEventListener('load', function() {
        if (typeof fbq !== 'undefined') {
          fbq('track', 'PageView');
        }
      });
    }
  })();
</script>
```

### Option B: Change the tag trigger

Change the GTM tag's trigger from "All Pages" or "DOM Ready" to **"Window Loaded"** to ensure `fbevents.js` has finished loading before calling `fbq()`.

### Option C: Use GTM's tag sequencing

Set the Meta Pixel base code tag as a **setup tag** for any tags that call `fbq()`. This ensures GTM fires them in order.
