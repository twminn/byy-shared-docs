### Background

### Implementation

Fire the event on the checkout page load (before payment form is shown):

```javascript
window.dataLayer = window.dataLayer || [];
window.dataLayer.push({
  event: 'initiate_checkout',
  value: planPrice,        // numeric, e.g. 97.00
  currency: 'USD',
  content_name: planName,  // e.g. 'Annual Membership'
  event_id: crypto.randomUUID()
```

### Where to Add

- Ensure it fires once per page load (not on re-renders)

## Action 3: Add Purchase Event Beacon Retry

### Problem

GA4 `purchase` events are undercounting real Stripe transactions. Root causes:
- Ad blockers blocking `gtag.js` or `analytics.js` entirely
- Users closing the browser/tab before the success page fully loads
- Network errors on the GA4 endpoint

### Solution: `navigator.sendBeacon` with Retry

Replace or supplement the current `trackPurchase()` with a beacon-based approach that is resistant to page unload:

```javascript
// In app/javascript/analytics/gtm.js — replace or wrap trackPurchase:

trackPurchase: function(transactionId, value, currency, items) {
  var eventData = {
    event: 'purchase',
    transaction_id: transactionId,
    value: value,
    currency: currency || 'USD',
    event_id: crypto.randomUUID(),
    items: items || []
  };

  // Primary: push to dataLayer (standard GA4 path)
  window.dataLayer = window.dataLayer || [];
  window.dataLayer.push(eventData);

  // Fallback: send via beacon to GA4 Measurement Protocol
  // This survives page close and ad-blocker scenarios
  try {
    var mpPayload = {
      client_id: getGA4ClientId(),
      events: [{
        name: 'purchase',
        params: {
          transaction_id: transactionId,
          value: value,
          currency: currency || 'USD',
          engagement_time_msec: 100
        }
      }]
    };
    navigator.sendBeacon(
      'https://www.google-analytics.com/mp/collect?measurement_id=G-6GPCZV3DHR&api_secret=YOUR_MP_API_SECRET',
      JSON.stringify(mpPayload)
    );
  } catch(e) {
    // Beacon failed — primary dataLayer push is the fallback
  }
}
```

### Setup Required

1. Create a Measurement Protocol API secret in GA4 Admin > Data Streams > Measurement Protocol API Secrets
2. Replace `YOUR_MP_API_SECRET` with the generated secret
3. Implement `getGA4ClientId()` to read the `_ga` cookie:
   ```javascript
   function getGA4ClientId() {
     var match = document.cookie.match(/_ga=GA\d+\.\d+\.(.+)/);
     return match ? match[1] : 'anonymous.' + Date.now();
   }
   ```

### Important Notes

- The Measurement Protocol secret should be treated as semi-sensitive (not as secret as an API key, but don't expose in public repos)
- The beacon approach does NOT deduplicate with the dataLayer push -- GA4 uses `event_id` for deduplication, so set the same `event_id` in both
- Test by blocking `gtag.js` in devtools and completing a test purchase -- the beacon should still deliver
